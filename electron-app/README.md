## 📥 نصب

### روش ۱: نصب از فایل Setup (پیشنهادی)

1. فایل `HTML-to-APK-Builder-Setup-1.0.0.exe` را دانلود کنید
2. روی آن کلیک کنید
3. مراحل نصب را دنبال کنید
4. برنامه از منوی Start قابل اجرا است

### روش ۲: اجرای پرتابل

1. فایل `HTML-to-APK-Builder-1.0.0-portable.zip` را دانلود کنید
2. آن را استخراج کنید
3. فایل `HTML to APK Builder.exe` را اجرا کنید

---

## 🛠️ ساخت از سورس کد

### پیش‌نیازها
- Node.js 18+
- npm یا yarn

### مراحل

```bash
# ۱. ورود به پوشه برنامه
cd electron-app

# ۲. نصب وابستگی‌ها
npm install

# ۳. اجرای حالت توسعه
npm run dev

# ۴. ساخت فایل نصب ویندوز
npm run dist:win
```

فایل نصب در پوشه `release/` قرار می‌گیرد.

## 📱 نحوه استفاده

### مرحله ۱: ورود کد HTML
- کد HTML خود را در ویرایشگر وارد کنید
- یا فایل HTML را آپلود کنید
- پیش‌نمایش زنده را ببینید

### مرحله ۲: تنظیمات
- نام برنامه را وارد کنید
- شناسه پکیج را تنظیم کنید
- آیکون برنامه را انتخاب کنید
- سایر تنظیمات را پیکربندی کنید

### مرحله ۳: ساخت APK
- دکمه "ساخت APK" را بزنید
- محل ذخیره را انتخاب کنید
- منتظر بمانید تا APK ساخته شود

### مرحله ۴: نصب
- فایل APK را به گوشی منتقل کنید
- روی آن کلیک کنید و نصب کنید

نیازی به نصب دستی نیست.

## 🐛 رفع مشکلات

### مشکل: Java نصب نیست
**راه‌حل:**
1. در برنامه، دکمه "نصب Java" را بزنید
2. یا به سایت https://adoptium.net/ بروید
3. Java JDK 17 را دانلود و نصب کنید

### مشکل: ساخت APK با خطا مواجه شد
**راه‌حل:**
1. مطمئن شوید اینترنت متصل است
2. اولین بار ممکن است Gradle دانلود شود (۱۰۰ مگابایت)
3. Android SDK نیز دانلود می‌شود (۲ گیگابایت)
4. صبر کنید تا کامل شود

### مشکل: APK روی گوشی نصب نمی‌شود
**راه‌حل:**
1. در تنظیمات گوشی، "Install from Unknown Sources" را فعال کنید
2. یا از `adb install` استفاده کنید
