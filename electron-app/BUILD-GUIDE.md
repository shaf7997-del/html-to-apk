# 🖥️ راهنمای ساخت برنامه دسکتاپ ویندوز

## 📋 مراحل ساخت

### ۱. نصب وابستگی‌ها

```bash
cd electron-app
npm install
```

### ۲. اجرای حالت توسعه

```bash
npm run dev
```

این دستور:
- سرور توسعه Vite را روی `http://localhost:5173` اجرا می‌کند
- برنامه Electron را با حالت توسعه باز می‌کند
- تغییرات کد به صورت زنده اعمال می‌شوند

### ۳. ساخت فایل نصب ویندوز

```bash
npm run dist:win
```

این دستور:
- برنامه را بیلد می‌کند
- فایل نصب ویندوز (.exe) می‌سازد
- فایل‌ها در پوشه `release/` قرار می‌گیرند

### ۴. فایل‌های خروجی

```
release/
├── HTML-to-APK-Builder-Setup-1.0.0.exe      # نصب‌کننده
├── HTML-to-APK-Builder-1.0.0.exe            # نسخه پرتابل
└── win-unpacked/                             # فایل‌های استخراج شده
```

### مرحله ۱: دریافت HTML
- کاربر کد HTML را وارد می‌کند
- یا فایل HTML را آپلود می‌کند

- شناسه پکیج

4. APK را بیلد می‌کند
5. فایل APK را تحویل می‌دهد

### مرحله ۴: نصب
- کاربر APK را به گوشی منتقل می‌کند
- روی گوشی نصب می‌کند

## 📦 ساخت خودکار با GitHub Actions

فایل `.github/workflows/build.yml`:

```yaml
name: Build Electron App

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: windows-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Node.js
      uses: actions/setup-node@v3
      with:
        node-version: '18'
    
    - name: Install dependencies
      run: |
        cd electron-app
        npm install
    
    - name: Build
      run: |
        cd electron-app
        npm run dist:win
    
    - name: Upload artifacts
      uses: actions/upload-artifact@v3
      with:
        name: windows-installer
        path: electron-app/release/*.exe
```

## 🐛 رفع مشکلات رایج

### مشکل: برنامه باز نمی‌شود
**راه‌حل:**
1. مطمئن شوید ویندوز ۱۰ یا بالاتر دارید
2. آنتی‌ویروس را موقتاً غیرفعال کنید
3. به عنوان Administrator اجرا کنید

### مشکل: ساخت APK با خطا مواجه شد
**راه‌حل:**
1. اینترنت را بررسی کنید
2. فضای دیسک کافی داشته باشید (۵ گیگابایت)
3. لاگ خطا را بررسی کنید

### مشکل: Java نصب نمی‌شود
**راه‌حل:**
1. به صورت دستی از https://adoptium.net/ دانلود کنید
2. نصب کنید
3. سیستم را ریستارت کنید
