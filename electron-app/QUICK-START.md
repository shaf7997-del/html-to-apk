# 🚀 شروع سریع - ساخت فایل نصب

## ❓ فایل نصب کجاست؟

فایل نصب **هنوز ساخته نشده**. باید آن را بسازید.

---

## ⚡ ساده‌ترین روش (۳ کلیک)

### مرحله ۱: نصب Node.js
اگر Node.js نصب نیست، از اینجا دانلود کنید:
```
https://nodejs.org/
```
**نسخه LTS** را دانلود و نصب کنید.

### مرحله ۲: اجرای اسکریپت ساخت
در پوشه `electron-app/`، روی فایل زیر کلیک کنید:
```
build-installer.bat
```

### مرحله ۳: نصب برنامه
بعد از اتمام ساخت، فایل نصب در این مسیر قرار می‌گیرد:
```
electron-app/release/HTML-to-APK-Builder-Setup-1.0.0.exe
```
روی آن کلیک کنید و نصب کنید!

---

## 📋 روش دستی (ترمینال)

اگر ترجیح می‌دهید از ترمینال استفاده کنید:

```bash
# ورود به پوشه برنامه
cd electron-app

# نصب وابستگی‌ها
npm install

# ساخت فایل نصب
npm run dist:win
```

فایل نصب در پوشه `release/` قرار می‌گیرد.

---

## 🎯 فایل‌های خروجی

بعد از ساخت، این فایل‌ها در پوشه `release/` قرار می‌گیرند:

| فایل | توضیح | حجم |
|------|--------|:---:|
| `HTML-to-APK-Builder-Setup-1.0.0.exe` | **نصب‌کننده** (پیشنهادی) | ~۵۰ MB |
| `HTML-to-APK-Builder-1.0.0.exe` | نسخه پرتابل (بدون نصب) | ~۱۲۰ MB |
| `win-unpacked/` | فایل‌های استخراج شده | ~۲۰۰ MB |

## ✅ بعد از نصب

1. برنامه را از منوی Start باز کنید
2. یا روی آیکون دسکتاپ کلیک کنید
3. کد HTML را وارد کنید
4. تنظیمات را پیکربندی کنید
5. دکمه "ساخت APK" را بزنید
6. فایل APK را دریافت کنید!

## 🐛 رفع مشکلات

### مشکل: "Node.js not found"
**راه‌حل:** Node.js را از https://nodejs.org/ دانلود و نصب کنید

### مشکل: "npm install failed"
**راه‌حل:**
```bash
# پاک کردن cache
npm cache clean --force

# دوباره نصب
npm install
```

### مشکل: "Build failed"
**راه‌حل:**
1. اینترنت را بررسی کنید
2. آنتی‌ویروس را موقتاً غیرفعال کنید
3. دوباره تلاش کنید
